Описание проекта

Программа предназначена для подбора индивидуальных тренировочных программ и ведения дневника тренировок. Данные пользователя хранятся в локальной базе данных, алгоритмы адаптации подстраиваются под цели и доступный инвентарь, а интерфейс доступен в трёх режимах отображения.

Основные возможности
Работа с пользователями:
Регистрация
Авторизация
Ведение профиля (рост, вес, возраст, цель)

Варианты интерфейса:
Консольная (Console)
Графическая (Swing)
Графическая (JavaFX)

Функционал тренировок:
Динамический подбор программы
Учёт прогресса и веса
Экспорт отчётов (Excel, PDF, DOC)

Настройки:
выбор цели тренировки
выбор места занятий
выбор формата экспорта

Архитектура проекта
model - классы-сущности (User, Exercise, WorkoutProgram),
dao - слой доступа к данным (UserDAO, WorkoutProgramDAO),
database - управление подключениями и инициализация БД,
view - реализации интерфейсов (console, swing, javafx),
patterns - модуль проектирования (factory, strategy, observer),
config - загрузка параметров из внешнего конфига

Используемые паттерны
Factory - для создания интерфейсов, DAO-компонентов и экспортных модулей,
Strategy - для динамического выбора алгоритма подбора тренировок,
Observer - для реактивного обновления состояния при изменении веса

Логика работы
1. Пользователь проходит регистрацию или авторизуется в системе
2. Загружаются параметры профиля (рост, вес, цель, место тренировок)
3. Через Strategy выбирается соответствующий алгоритм подбора программы
4. При записи веса срабатывает Observer -> логируется прогресс, обновляются экраны
5. Пользователь экспортирует отчёт в выбранном формате (Excel, PDF, DOC)

Запуск проекта

🔹 1. Сборка
mvn clean package

🔹 2. Запуск (консоль / Swing)
java -cp "target/classes;target/lib/*" com.workout.app.MainConsole
java -cp "target/classes;target/lib/*" com.workout.app.Main

🔹 3. Запуск JavaFX
java --module-path "target/lib" --add-modules javafx.controls,javafx.fxml -cp "target/classes;target/lib/*" com.workout.app.MainJavaFX

Пример входных данных
{

функция help
